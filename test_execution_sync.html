Execution Synchronization Test

This test verifies that execution data (completion status) is properly synchronized across shared items in different flows.

Test Scenario

1. Create Flow A with some evidence items

2. Clone Flow A to create Flow B

3. Tick a box in Flow B (execution mode)

4. Share Flow B to create Flow C

5. Verify that the ticked box in Flow B is also ticked in Flow C
